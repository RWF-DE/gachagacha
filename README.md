# YoSoro! お宝ガチャ（電波祭2026）

電波祭の本部テントに置いた iPad 1台で、来場者が無料の景品抽選をするためのアプリです。
**インターネットがなくても iPad の中だけで動きます**（静的 HTML/CSS/JS + Service Worker + IndexedDB の PWA）。
ビルド作業・外部サービス・外部CDNは不要です。仕様の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

- 参加者：「本校の学生」は学籍番号を入力（電波祭の両日で1回）、「本校学生以外」は入力なしで1回。個人情報は集めません。
- 抽選：日ごとに独立した「引いたら戻さないくじ箱」。乱数は `crypto.getRandomValues`。結果は **IndexedDB に保存が完了してから** 演出が始まります。
- スタッフ：結果画面の「お渡し済み・OK」を **1秒長押し** で確定し、次の人へ進みます。

## ファイル構成

```
index.html / manifest.webmanifest / sw.js   アプリ本体・PWA
css/   tokens.css（色・書体）・app.css（共通部品・スタッフ画面）・poster.css（プレイヤー画面・演出）
js/    app.js（画面の流れ）・admin.js（スタッフ画面）・db.js（IndexedDB）・lottery.js（抽選）・config.js（既定の景品）
       stage.js / screens.js / poster.js（ポスター画面・演出）・sound.js（効果音）
fonts/ 自前ホストのフォント（woff2・OFL。dev/build-fonts.py で作り直せる）
icons/ ホーム画面アイコン（dev/render-icons.mjs で icon.svg から書き出し）
tests/ lottery.test.mjs（単体）・e2e.mjs（Playwright）
```

すべて相対パスなので、どのフォルダに置いても動きます。

## 公開（デプロイ）の方法

どちらも「フォルダの中身をそのまま置くだけ」です。**HTTPS で配信されることが必須**です（Service Worker の条件）。

### A. denpasai.jp に置く
このフォルダの中身を、サーバーの `public/gacha/` にコピーします。
→ `https://denpasai.jp/gacha/` で開けます。

### B. GitHub Pages
リポジトリの Settings → Pages → **Build and deployment: Deploy from a branch** を選び、ブランチ（例：`main`）と `/ (root)` を指定します。
→ `https://<ユーザー名>.github.io/gachagacha/` で開けます。

### 更新して再公開するとき
ファイルを変更したら **`sw.js` の先頭の `VERSION` を 1 つ上げて** から公開してください（上げないと iPad は古いキャッシュを使い続けます）。
iPad 側では、スタッフ画面の「状態」→「更新を適用」で切り替えます（未確認の抽選が無いときだけ押せます。本番中に自動で再読み込みはしません）。
ファイルを追加したときは `sw.js` の `PRECACHE` にも追加してください。
フォント（`fonts/*.woff2`）は日本語の動的な文字（賞の名称・景品名など）に備えて JIS 第1水準漢字＋かな＋画面内の全文字を含めたサブセットです。画面の文言を増やしたら `python3 dev/build-fonts.py`（要 fonttools・brotli・npm）で作り直してください。

## iPad への入れ方（本番の前日までに）

1. iPad を Wi-Fi につなぎ、Safari で公開URLを開く。
2. 画面左上の **ロゴ（舵輪マークと「電波祭 2026 / DENPASAI 2026」の文字）を3秒長押し** → 初回はセットアップ画面が出るので、PIN・景品の本数・学籍番号のルールを確認して「はじめる」。
3. もう一度ロゴを3秒長押し → PIN → **「状態」で「オフライン準備完了」と表示されるまで待つ**（数十秒）。「保存領域の保護」も「保護されています」になるのが望ましい（許可を求めるボタンあり）。
4. Safari の共有ボタン → **「ホーム画面に追加」**。
5. **ホーム画面のアイコンから起動**する（以後はこちらを使う。Safari で開いたデータとは別の保存領域になることがあるため、セットアップはアイコンから起動した状態でやり直すのが確実）。
6. **機内モードにして**、アイコンから起動して抽選が最後までできることを確認する（リハーサル）。
7. リハーサルのデータは、スタッフ画面「バックアップ・リセット」→ **本番リセット**（「リセット」と入力＋PIN）で消す。

## 当日の運用チェックリスト

**開始前**
- [ ] 充電・自動ロックを「なし」に（設定 → 画面表示と明るさ → 自動ロック）。
- [ ] 「アクセスガイド」で固定（設定 → アクセシビリティ → アクセスガイド。起動後にホームボタン/サイドボタンを3回押して開始。他のアプリに移れなくなります）。
- [ ] スタッフ画面の「状態」で、開催日（1日目/2日目）・オフライン準備完了・本数未定の景品の警告を確認。
- [ ] 音量とサイレントスイッチを確認（設定タブで効果音の ON/OFF・音量）。

**運用中**
- 結果画面は自動では閉じません。景品を渡したら、スタッフが「お渡し済み・OK」を1秒長押し。
- 景品が足りなくなったら、スタッフ画面「在庫」の「± 調整」で残数を変更（理由がログに残ります）。ブルダックが届かない場合は残数を0に。
- 参加者が入力途中で離れた場合は、90秒で自動的に最初の画面に戻ります。
- **バックアップ**：スタッフ交代のとき・各日の終了時に「バックアップ・リセット」→「バックアップを書き出す」→「保存・共有する」（AirDrop / ファイル / メール等）。最終バックアップ以降の件数が表示されます。
- 参加済みの学生に「参加済み」と出たら、本人確認のうえ、スタッフ画面「履歴」で番号の末尾2桁を確認できます。

**2日目に切り替えるとき**
1. 1日目終了時にバックアップを書き出す。
2. スタッフ画面「状態」→ 開催日「2日目」を押して確認。**1日目の残りは自動で繰り越されません**（確率が変わるため）。繰り越したい場合は「在庫」で手動で追加。
3. 学生の参加済み記録は両日を通して有効です（1日目に参加した学生は2日目は不可）。

**困ったとき**
- 「保存できませんでした。スタッフを呼んでください」：景品は決まっていません（減算もされていません）。「最初にもどる」からやり直してください。繰り返す場合はバックアップを書き出し、アプリを再起動。
- 結果表示中に落ちた／固まった：再起動すると **同じ結果が再表示** されます（新しい抽選はできません）。OK を長押ししてください。OK が効かない場合は、ロゴ3秒長押し → 「履歴」→「確認済みにする」。
- データが消えてしまった：初回セットアップ画面の「バックアップから復元する」、またはスタッフ画面「バックアップから復元」で最新のバックアップを読み込みます。
- 「保存領域の保護」が未許可のままの場合：Safari の履歴/サイトデータ消去でデータが消えることがあります。こまめにバックアップしてください。
- PINを忘れた：スタッフ画面に入れません。バックアップがあれば、Safari の「サイトデータを削除」後に復元する方法があります（運営責任者へ）。

## テスト

```sh
# 単体テスト（抽選・学籍番号の正規化/検証・バックアップ検証）
npm test                    # = node --test tests/*.test.mjs   （Node 20 以上）

# E2E（Playwright + Chromium。サーバーは自動で起動）
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node tests/e2e.mjs
```

- E2E は `playwright` を `/opt/node22/lib/node_modules/playwright` から読み込みます。別の場所なら `PLAYWRIGHT_MODULE=/path/to/playwright` を指定。
- 配信するフォルダは `E2E_ROOT=/path` で変更できます（既定はこのリポジトリ）。
- 演出は `?fast=1` で1秒未満に短縮されます（E2Eで使用）。
- E2E が操作する要素：`data-testid="spin-button"`（タップでまわす）、`wheel`（舵輪）、`result-card`（結果カード）。

## プライバシー

- 学籍番号は「参加済みの確認」だけに使い、端末（IndexedDB）内にのみ保存します。サーバーには送信しません。URL・ログ・エラーメッセージにも出しません。
- 氏名・メール・電話などは一切集めません。本校学生以外にはダミー番号も割り当てません。
- バックアップ（JSON）とCSVには学籍番号が含まれます。**イベント終了後、iPad のデータ（スタッフ画面「全初期化」）と、書き出したバックアップ/CSV のファイルを削除してください。**
